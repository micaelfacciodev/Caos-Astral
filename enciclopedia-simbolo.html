O que é um símbolo?

Um símbolo não é decoração nem enigma. É uma unidade de sentido que carrega mais do que a linguagem literal consegue empacotar, e muda de leitura conforme o sistema que o lê.

Um planeta, um hexagrama, uma cena de grau, nenhum desses é uma coisa "de verdade" no sentido de objeto físico com uma única função. São condensações: um jeito de empacotar uma constelação de significados relacionados num único ponto de referência, pra que dois sistemas diferentes (uma tradição inteira e a experiência concreta de uma pessoa) consigam conversar através dele.

O erro comum é tratar o símbolo como container fechado, "Marte significa X, ponto final". O que este projeto assume é o oposto: o símbolo é um convite à leitura, não uma definição de dicionário. O mesmo símbolo muda de peso dependendo de onde aparece no sistema (uma casa, um trânsito, uma pergunta específica), é isso que separa leitura de decoreba.

Este verbete está em construção, assim como o resto do sistema, uma peça de cada vez. A ideia é ficar mais preciso com revisão, não parecer completo antes da hora.
